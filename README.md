# Bing App

An interactive mobile prototype and component workbench for exploring the Bing App
experience. It brings product flows, key screens, and reusable components together
so designers, developers, and product managers can review how the experience looks
and works.

**[Explore the live prototype](https://elevendy-git.github.io/Bing-app/)**

## What’s inside

- **Prototype** — Try connected search, browsing, recent activity, private mode,
  and voice search flows.
- **Key screens** — Review the main screens and their design states.
- **Library** — Explore the shared components used throughout the prototype.

Built with React, TypeScript, and Vite, using an iPhone 18 Pro canvas and
iOS-inspired motion. Live search and news data, along with Microsoft personal-account
sign-in, help bring the prototype closer to a real product experience.

## Run locally

Requires Node.js 24 LTS.

```sh
npm ci
npm run dev
```

Open [localhost:5174](http://localhost:5174/).
